# master english pronunciation with echo method  

It can turn any web content into your personal English pronunciation lab. Paste a link, get the transcript, and echo like a native.  

```bash
make setup            # venv + deps + build UI
make service-install  # always-on API on :5050
```

**iPhone:** open the site in Safari → Share → **Add to Home Screen**. Opens as a standalone app (Word bank + Echo). Needs Tailscale (or LAN) to reach your Mac API.
